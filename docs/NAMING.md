# HCB naming

- **HCB** = Host Compatibility Baseline — the concept/abbreviation.
- **`dsh-hcb`** = the repo/package that implements it. This is the only official name for the data/gate layer.
- **`dsh-standards`** = the flagship: rules, checker, ENTRY/FLOW/BOOST definitions. HCB is a subproject of it.

Retired `hcb` / `hcb-*` repos are pointers to `dsh-standards` + `dsh-hcb`; do not use them for new work.

Do not use "HCB" to imply endorsement by PerryLink, DeepSeek, or dsh-standards. Forks must rename and link to the canonical repo.
