# HCB governance

HCB is a **subproject of [dsh-standards](https://github.com/PerryLink/dsh-standards)**, not an independent project or organization.

- **Rules/checker/spec**: owned by dsh-standards.
- **Compatibility/tracks data, risk, gate, CI**: owned by this repo (`dsh-hcb`).
- **Decisions**: follow dsh-standards maintainers; data changes are PR-reviewed here.
- **No separate organization** is planned. `hcb`/`hcb-*` repos are retired pointers.

If HCB later needs a neutral counterparty, the escape hatch is a new org/repo (`hcb-labs` or `hcbkit`) with a separate governance doc — not a rename of this subproject.
